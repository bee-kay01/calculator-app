# Calculator App

A simple, responsive calculator built with HTML, CSS, and JavaScript. No frameworks, no dependencies — just vanilla web tech.

## Features

- Basic operations: addition, subtraction, multiplication, division
- Percentage (%)
- Square (x²) and square root (√x)
- Positive/negative toggle (±)
- Clear (AC) and delete last digit (DEL)
- Full keyboard support
- Clean dark-themed UI

## Getting Started

1. Clone or download this repository
2. Open `index.html` in any web browser — no build step or server required

### Keyboard Shortcuts

| Key         | Action              |
|-------------|---------------------|
| `0`–`9`     | Enter numbers       |
| `.`         | Decimal point       |
| `+`         | Add                 |
| `-`         | Subtract            |
| `*`         | Multiply            |
| `/`         | Divide              |
| `Enter` / `=` | Calculate result  |
| `Backspace` | Delete last digit   |
| `Escape`    | Clear all           |
